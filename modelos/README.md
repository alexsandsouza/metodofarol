# Modelos preenchíveis

- [Briefing](BRIEFING.txt): contexto e condições da aula.
- [Perfil disciplinar](PERFIL_DISCIPLINAR.txt): evidências, métodos e critérios do campo.
- [Registro de fontes](REGISTRO_FONTES.csv): inventário das fontes acadêmicas.
- [Matriz de alinhamento](MATRIZ_ALINHAMENTO.md): relação entre objetivos, prática e avaliação.
- [Checklist de publicação](CHECKLIST_PUBLICACAO.md): conferência docente.
- [Registro de melhorias](REGISTRO_MELHORIAS.md): evidências e decisões após a aula.

Os campos vazios são intencionais. Preencha-os com os dados reais da disciplina; não trate exemplos gerados por IA como informações institucionais.
