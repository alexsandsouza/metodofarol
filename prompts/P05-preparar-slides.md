# P05 - Preparar slides

Substitua os campos entre colchetes antes de executar.

## Comando para copiar

Aplique as REGRAS_CENTRAIS FAROL ao BRIEFING e ao PERFIL_DISCIPLINAR fornecidos. Use apenas fontes acadêmicas selecionadas para sustentar conceitos. Cite o suporte disponível; não invente referências. Identifique exemplos criados, interpretações e lacunas. Use o módulo 04-multimodal e o roteiro aprovado abaixo: [COLAR ROTEIRO]. Produza um storyboard com quantidade de slides compatível com a aula. Para cada slide: título, mensagem, conteúdo, visual proposto, referência e notas do professor. Descreva figuras com precisão. Não afirme ter criado um PPTX se apenas entregou texto.
