# P06 — Preparar material de estudo

Substitua os campos entre colchetes antes de executar.

## Comando para copiar

Aplique as REGRAS_CENTRAIS FAROL ao BRIEFING e ao PERFIL_DISCIPLINAR fornecidos. Use apenas fontes acadêmicas selecionadas para sustentar conceitos. Cite o suporte disponível; não invente referências. Identifique exemplos criados, interpretações e lacunas. Use o módulo 04-multimodal. Gere um texto universitário para o aluno a partir do roteiro aprovado [COLAR]. Inclua conceitos, exemplo comentado, limites da analogia quando usada, contraponto pertinente, síntese e perguntas de recuperação. Apresente bibliografia somente com dados efetivamente disponíveis.
